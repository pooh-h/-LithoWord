# 岩语 · LithoWord

> 地质学与矿物学的专业词汇工作台。读 Zotero、看视频时连按两次 Tab，把生词连同原句一起收进来；自动还原词形、判断学科、拆词根、配例句，然后用固定的间隔阶梯（1/2/4/7/15/30/60 天）在最合适的时候让你再见它一面。

纯本地：数据存在浏览器 `localStorage`，不上传；Zotero 只读你主动导出的题录，不碰数据库。

---

## 一、三步开始

### 先把它拿到自己电脑上

三种方式，挑一个：

```powershell
# 1) 克隆（推荐，以后可以 git pull 更新）
git clone https://github.com/pooh-h/-LithoWord.git
cd -- -LithoWord

# 2) 不装 git：在仓库页点 Code → Download ZIP，解压即可
# 3) 只要成品包：在 Releases 页下载 LithoWord-v1.x.zip
```

拿到后目录结构不变，**没有硬编码路径**，放在任何位置都能跑（`启动.bat` 用 `%~dp0`，启动器用 `$PSScriptRoot`）。

> 想在浏览器里先看看界面？GitHub Pages 上有一份在线版：<https://pooh-h.github.io/-LithoWord/>
> 在线版能看界面、背词、导数据，但 Tab 取词和离线词典需要本机的取词助手，得按下面的步骤在自己电脑上跑。

### 然后

1. 双击 **`创建桌面快捷方式.bat`**（只需一次），桌面会出现带图标的「岩语 LithoWord」。
   以后就双击这个图标——或双击项目里的 `启动.bat`，两者行为完全一样。
2. 桌面图标会做四件事，全自动：找 Python → 后台静默启动取词助手 → 等接口就绪 → 打开浏览器。
   - 助手已经在跑时不会再起第二个，直接开网页；
   - 起不来会弹窗告诉你原因（端口被占、找不到 Python、杀毒拦截）并给出日志路径 `data\cache\launcher.log`；
   - 全程没有黑框闪过：快捷方式调用的是 `powershell -WindowStyle Hidden -File tools\launch.ps1`。
3. 在 Zotero、PDF 阅读器、B 站或任何播放器里，选中一个词或一句话，**连按两次 Tab**：
   浏览器被叫到前台，小窗已经带着剪贴板里的词/原句。回车收录，Esc 关闭。

> 单按 Tab 不会被打断，仍然是正常的切换焦点；只有 420ms 内的两次 Tab 才触发取词。
> 如果不喜欢，可在 `tools/agent_config.json` 里把 `hotkey` 改成 `ctrlTab`。

要停掉助手：双击 **`停止取词助手.bat`**，或任务管理器结束 `pythonw.exe`。
想看实时日志：双击 **`tools\取词助手.bat`**（控制台模式）。

没有 Python 也能用：直接双击 `index.html`，或在页面里点右上角「收录」，只是没有全局 Tab 取词。

## 二、它替你做的六件事

| 能力 | 说明 |
|---|---|
| 词形还原 | `studies → study`、`gneisses → gneiss`、`mineralizing → mineralize`；bedding / sorting / weathering 这类本身是术语的词不会被误拆 |
| 学科分类 | 13 个地质学领域 + 7 种使用场景；命中词库给 0.96 置信度，按词根猜给 0.55，完全没线索时诚实标成「通用学术 0.25」，并说明依据 |
| 音标 / 词根 / 例句 | 每个词都有英式 IPA、逐段词根（`photo(光) + synthesis`）、中英例句和学术搭配 |
| Zotero 语境 | 收录时选好文献、页码、原句；复习卡上直接显示原文，`zotero://select` 一键跳回 Zotero |
| 每日复习 | 每天最多 30 张到期卡 + 4 张随机抽查；`空格` 翻面，`1`–`4` 评分；间隔按固定阶梯 1 → 2 → 4 → 7 → 15 → 30 → 60 天走，忘记的卡 2 天后回来 |
| 学科高频词库 | 146 个地质/矿物核心词，按 10 个词包和 13 个领域交叉索引，可整包开背 |
| 学科卡片墙 | 词库页「学科卡片」：点一个领域（构造地质学、岩石学……），每个词是一张方形卡片；点开卡片看释义和例句，背面三个按钮 `会了 / 很难 / 不会` 就是难度标注，标注次数会累计在卡片上，也决定它下次什么时候回来 |
| 搜我的词 | 生词本右上搜索框按单词 / 音标 / 中文释义 / 学科 / 原句 / 搭配搜；顶部搜索框输入已收录的词回车会直接打开词条，输入新词才是收录 |
| 离线词典 | 收录新词时自动补音标和中文释义；77 万条英汉词条放在本机 `data/dict.sqlite`，查一个词约 1 毫秒，不联网 |
| 有道联网词典 | 离线库缺的东西（中英例句、真人发音、太生僻没收录的词）再问一次有道公开词条接口，免费、免注册；查过的词缓存在 `data/cache/online.sqlite`，第二次不再联网 |

### 间隔阶梯（不再有 47 天这种数）

复习间隔是一组固定天数，`1 → 2 → 4 → 7 → 15 → 30 → 60`，每个词停在其中一档：

| 点这个 | 发生什么 |
|---|---|
| 忘记 | 回到 2 天后重来，忘记次数 +1 |
| 模糊（有点难） | 退一档 |
| 记得 | 进一档 |
| 很简单 | 进两档，最多 60 天 |

到 15 天以上就算「已掌握」——已掌握的词大概半个月到一个月才见一次，老忘的词两三天就回来一次。每天的到期卡上限默认 30 张，超出的顺延到明天。

### 离线词典（ECDICT）

词库外的词（比如 `cataclasite`、`boudinage`）收录时，助手会先查本机离线词典：

1. 输入框下方的预览会立刻显示音标和释义，确认无误再收录；
2. 收录后音标、中文释义自动写进词条，**已经有内容的字段不会被覆盖**；
3. 中文释义里带学科线索时（岩石 / 矿物 / 构造 / 地层……），学科会从「通用学术 0.25」提升到对应领域并标为「词典释义推断」，依据写在词条的判定依据里，随时可手动改；
4. 抽屉里还会多一段 `DICTIONARY · 词典`：词条、词形变化、常用度、来源。老词条缺释义时，抽屉里点「用离线词典补全」即可。

数据源是 MIT 协议的 [ECDICT](https://github.com/skywind3000/ECDICT)（有道官方离线包加密且不可再分发，所以用这份开源词表替代）。设置页「离线词典」面板显示安装状态；没装过就点一次「下载并安装离线词典」（约 30 MB，本机实测建库 7 秒，77 万条）。也可以手动：

```powershell
python tools/dict_build.py          # 下载 + 建库
python tools/dict_build.py --check  # 只看状态
```

兜底开关在设置页：离线词典查不到时是否再问一次在线词典（`dictionaryapi.dev`，只发单词本身）。关掉它就完全离线。

### 有道联网词典

「离线词典」面板里第二个开关是 `有道联网词典`（默认开）。它只在两种时候联网：

1. 离线库没有这个词（生僻地质词、新造词）；
2. 离线库有词条但缺音标、缺例句、缺发音时，补上中英对照例句和真人发音。

用的是有道公开词条接口（`dict.youdao.com/jsonapi`），免费、不需要 API key，也**不需要注册**。接口由本机取词助手代行，网页端不直接跨域请求；查过的结果缓存在 `data/cache/online.sqlite`（30 天），同一个词第二次查是本地读取。断网时自动跳过，不会卡住收录流程。

想完全离线就把这个开关关掉，那时只有 `data/dict.sqlite` 在工作。

镜下描述、野外记录、图版与图注、方法与仪器、成因与讨论、资源评价、课堂与综述。

## 三、和 Zotero 打通（只读，不写库）

1. Zotero 里选中要用的文献（或整个分类）→ 右键 **导出条目** → 格式选 **CSL JSON**（BibTeX / RIS 也支持）。
2. 打开「文献」页，把文件拖进虚线框，或点「选择文件」。
3. 导入时按 DOI / itemKey / 标题去重；收录单词时就能选这篇文献、填页码和原句。
4. 题录里有 8 位 itemKey 时，复习卡和生词本会出现「Zotero 回跳」，点它直接定位到条目。

`itemKey` 是 Zotero 条目的 8 位键（如 `K7F2M9QX`），从「复制条目链接」或导出文件里能看到。示例题录没有 itemKey，所以只提示、不回跳。

> 本会话里 Zotero 写入是关闭的，所以这里只做「导出 → 导入」的单向读取，不会改你的文库。

## 五、数据与导出

- 生词、题录、复习记录都在浏览器的 `localStorage`（键名 `lithoword.v2`）。

## 七、排错

| 现象 | 处理 |
|---|---|
| 页面底部一直 `AGENT OFFLINE` | 双击桌面图标（或 `启动.bat`）；起不来会弹窗说明原因，详细日志在 `data\cache\launcher.log` 和 `tools\agent.log`。端口被占用时助手会直接退出 |
| Tab ×2 没反应 | 确认助手在线；某些游戏/远程桌面会吞掉全局钩子，可改用 `ctrlTab` |
| 改了快捷键不生效 | 设置页的选项只记录偏好，实际以 `tools/agent_config.json` 为准，改完要重启助手 |
| 端口 8737 冲突 | 改 `tools/agent_config.json` 的 `port`，并在设置页填同一个端口 |
| 在线补全失败 | 查词走 `dictionaryapi.dev`，需要联网；失败时不会伪造音标，会明确标「词库未收录」 |
| 设置页显示「未安装」或「取词助手没连上」 | 词典要走本地助手：双击桌面图标（或 `启动.bat`），再点「重新检测」；仍旧不行就手动 `python tools/dict_build.py` 看日志 |
| 词典下载卡住 | 下载源依次是 npmmirror → npmjs → jsDelivr → ghproxy，任一成功即停；网络都不通时把 `ecdict.csv` 放进 `data/cache/` 再跑 `python tools/dict_build.py` |
| 收录了词还是没释义 | 该词 ECDICT 也没收录（极冷门的属名/地名）；抽屉里点「用离线词典补全」可重试，或打开在线兜底开关 |
| 想彻底停掉 | 双击 `停止取词助手.bat`（按 PID 精确结束，不误杀别的 Python） |

## 八、已知限制

- 全局取词助手只支持 Windows（用 Win32 低级键盘钩子）。
- 离线词典是 ECDICT 的英汉词表：音标用的是它自己的标注系统（形如 `'slikәn,said`），个别词条没有音标，界面会写「音标待补」而不是编一个；释义按义项分行，不做例句，例句仍来自词库。
- 词典释义反推学科只是启发式：只在词库和词根都没有线索时兜底，置信度 0.48–0.55，判定依据里写明「词典释义推断」，不对就手动改。
- 在线查词只补英文释义与音标；中文释义、词根仍以本地词库为准，缺失时会留白而不是瞎编。
- Zotero 是「导出再导入」的只读集成，不做实时双向同步。
- 复习算法是固定间隔阶梯（1/2/4/7/15/30/60 天），不是完整的 SM-2 公式：没有按科目调参，也没有手写复习计划。
